# Usman App Hub — Official APK Releases

This public repository hosts **signed APK binaries and release notes only**. Application source code is maintained separately.

## Install and update
Stable APKs will appear under [Releases](https://github.com/usmanjhawri/Usman-App-Hub-Releases/releases). Android will request confirmation before installation. The in-app updater checks the latest published non-prerelease GitHub Release.

**No public APK release has been published yet.** Do not upload unsigned or test-only builds. Updating an existing installation requires the same package ID, matching signing certificate, and a newer version code.

## Release verification
Each stable release must include a signed APK, version-specific release notes, and a SHA-256 checksum. Verify the package ID and signing certificate before publishing.

Never publish signing keys, personal access tokens, or private CI artifacts. Contact: usmanjhawri@gmail.com
